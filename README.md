# Brew Center ☕

แอป companion สำหรับบาริสต้าและร้านคาเฟ่ · ใช้บนมือถือในร้านจริง · ไม่มี login ไม่มี server ข้อมูลอยู่ในเครื่อง 100%

🔗 **https://project-sy789.github.io/Brew-Center/**

---

## 📸 Features / ความสามารถ

| Feature | รายละเอียด |
|---------|-----------|
| 📚 **เมนูเครื่องดื่ม** | 8 สูตรเริ่มต้น (ไอซ์ลาเต้, คาปูชิโน่, มัทฉะ, ชาไทย, สมูทตี้, ช็อกโกแลตปั่น, โซดา, Dirty Coffee) |
| 🔥 **โหมดเริ่มชง** | นำทางทีละขั้นตอน พร้อมจับเวลา แจ้งเตือนเมื่อครบเวลา |
| 💰 **คำนวณต้นทุน & กำไร** | ใส่ราคาวัตถุดิบต่อหน่วย → คำนวณต้นทุนรวม, ราคาขาย, กำไร, margin % |
| 📐 **ปรับขนาดเสิร์ฟ** | ×0.5 / ×1 / ×2 / ×4 / ×10 ระบบปรับส่วนผสมอัตโนมัติ |
| 🌡️ **คู่มืออุณหภูมิ** | อุณหภูมิที่เหมาะสมสำหรับ espresso, pour over, cold brew, matcha, ชาไทย, milk steaming |
| 🔄 **แปลงหน่วย** | oz / shot / tbsp / tsp / cup → ml |
| 🧊 **คำนวณน้ำแข็ง** | ปรับสูตรเมื่อใส่น้ำแข็ง (no ice / regular / extra) |
| 📦 **Stock Tracker** | ติดตามสต็อกวัตถุดิบ พร้อมแจ้งเตือนเมื่อใกล้หมด |
| 📓 **Brew Log** | บันทึกการชง ให้ดาว 1-5, โน้ต, แนบรูป |
| ✦ **Import ด้วย AI** | ก็อป prompt → วางใน Claude/ChatGPT → ได้สูตรใน format ของแอป |
| 🌙 **Dark mode** | โหมดมืด/สว่าง |
| 🌐 **ไทย/อังกฤษ** | สลับภาษาได้ทุกเมื่อ |
| 📱 **PWA** | ติดตั้งลงหน้าจอโฮม เปิดเต็มจอ ใช้ offline ได้ 100% |
| 💾 **Backup** | Export/Import JSON + สำรองอัตโนมัติทุกวัน |

## 🚀 Deploy

1. Fork repo นี้
2. ไปที่ Settings → Pages → Source: `main` branch → Save
3. เว็บจะอยู่ที่ `https://<your-username>.github.io/Brew-Center/`

หรือเปิด `index.html` ใน browser ได้ทันที — ไม่ต้อง build อะไรเลย
